## Key Learnings

### ✅ Best Practices
1. Always call `flutter pub get` after updating ARB files
2. ARB parameter keys are functions, not strings
3. Use helper functions for status/severity localization
4. Dictionary mapping for filter labels is cleaner
5. Hot restart required after language change
6. Keep medical terminology consistent across all pages

### ✅ Common Patterns
- Import: `import '../../../../generated/app_localizations.dart';`
- Usage: `final l10n = AppLocalizations.of(context)!;`
- Simple: `Text(l10n.keyName)`
- With param: `Text(l10n.keyName(value))`
- Multiple params: `Text(l10n.keyName(value1, value2))`

### ✅ Pitfalls to Avoid
- ❌ Don't use `.replaceAll()` on ARB functions
- ❌ Don't forget to add keys to all 3 ARB files
- ❌ Don't use generic key names (use descriptive names)
- ❌ Don't forget hot restart after language change
- ❌ Don't skip `flutter pub get` after ARB changes
